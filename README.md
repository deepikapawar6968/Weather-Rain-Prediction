## Dataset

This project uses a real-world historical weather dataset containing daily weather observations from different locations.

The dataset includes weather-related information such as temperature, rainfall, humidity, pressure, wind conditions, cloud coverage, sunshine, and other meteorological factors.

The dataset used for this project is included in this repository.

### Features

The dataset contains the following features:

- Date
- Location
- MinTemp
- MaxTemp
- Rainfall
- Evaporation
- Sunshine
- WindGustDir
- WindGustSpeed
- WindDir9am
- WindDir3pm
- WindSpeed9am
- WindSpeed3pm
- Humidity9am
- Humidity3pm
- Pressure9am
- Pressure3pm
- Cloud9am
- Cloud3pm
- Temp9am
- Temp3pm
- RainToday
- RISK_MM
- RainTomorrow

### Target Variable

The target variable is:

`RainTomorrow`

The model predicts whether it will rain the following day:

- `Yes` - Rain is expected tomorrow.
- `No` - Rain is not expected tomorrow.
